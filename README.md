# Portfolio — Renzo Lenes

Portfolio personal de **Renzo Lenes**, Semi-Senior Full-Stack Developer especializado en desarrollo fullstack e IA aplicada (LLMs, RAG y automatización).

🔗 **En vivo:** [portfolio-fullstack-topaz.vercel.app](https://portfolio-fullstack-topaz.vercel.app)

## Stack

- **Framework:** Next.js 15 + React 19 + TypeScript
- **UI:** [Once UI](https://once-ui.com) + Sass
- **Contenido:** MDX para casos de estudio de proyectos
- **Deploy:** Vercel

## Proyectos destacados

- **VentIA** — Plataforma SaaS multitenant para e-commerce (Next.js + FastAPI + Rails, Auth0, Shopify, IA generativa).
- **Chatbot UPC** — Asistente conversacional RAG por WhatsApp (FastAPI, LangChain, OpenAI, pgvector).
- **FleetCare** — Monitoreo IoT de flotas con IA — 1er lugar Hackathon SHEM 2025.
- **FINZ** — App de finanzas personales (Next.js, Clerk, Drizzle, Neon).

## Desarrollo local

Requiere Node.js v18.17+.

```bash
npm install
npm run dev
```

- **Configuración:** `src/resources/once-ui.config.js`
- **Contenido (perfil, experiencia, skills):** `src/resources/content.js`
- **Proyectos:** añade un `.mdx` en `src/app/work/projects/`
